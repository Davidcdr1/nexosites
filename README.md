# NexoSites

Landing responsive para ofrecer desarrollo web.

## Local
npm install
npm run dev

## Vercel
Importa el repositorio y añade:
- `RESEND_API_KEY`
- `CONTACT_TO_EMAIL=dcuencadelrio@gmail.com`
- `CONTACT_FROM_EMAIL` con una dirección de un dominio verificado en Resend.

## Antes de publicar
La web está configurada para `https://nexosites.vercel.app`. Si más adelante compras un dominio propio, actualiza la URL canónica, robots.txt y sitemap.xml.

Los textos legales incluidos son un borrador informativo y deben revisarse y mantenerse actualizados según tu situación y los servicios/proveedores que utilices.


### Portfolio demos
Las tres tarjetas del portfolio ahora incluyen demos navegables dentro de la propia aplicación: restaurante, peluquería y consultoría. Son proyectos ficticios claramente marcados como demo.
